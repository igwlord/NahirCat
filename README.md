# Nahir Cat Sitter

Sitio estático listo para publicar en Netlify. Conserva el contenido de la web anterior y sus nueve fotografías, con una presentación nueva para desktop y móvil.

## Publicación en Netlify

1. Conectar el repositorio [igwlord/NahirCat](https://github.com/igwlord/NahirCat) a Netlify y usar la rama `main`.
2. Dejar el comando de build vacío. El directorio de publicación es `.` (configurado en `netlify.toml`). Cada cambio publicado en `main` podrá generar un nuevo deploy.
3. El formulario de contacto abre la aplicación de correo del visitante con la consulta preparada para `Nahirtranfo@outlook.com`. El visitante debe confirmar el envío desde su correo.

No se necesitan dependencias ni variables de entorno. Para probar localmente se puede servir la carpeta con cualquier servidor HTTP estático.
